# 🏙️ Air Quality Index Prediction

## 📌 Description

Developed an air quality prediction system using a **hybrid deep learning architecture**, combining:

- **ARIMA** for linear extraction
- **Transformer-based Attention CNN (ACNN)** for feature encoding
- **Bi-directional LSTM (Bi-LSTM)** optimized with **Quantum Particle Swarm Optimization (QPSO)** for nonlinear decoding
- **XGBoost** as a final ensemble regressor

The model forecasts **hourly AQI in Seoul**, integrating statistical and deep learning models for superior accuracy.

---

## 💻 Technologies & Skills

- **Time Series Analysis:** ARIMA (trend & seasonality extraction)
- **Deep Learning:** Transformer-based ACNN encoder; Bi-LSTM decoder
- **Optimization:** QPSO for LSTM hyperparameter tuning
- **Machine Learning:** XGBoost for final prediction refinement
- **Data Engineering:** Preprocessing, missing data imputation (previous day same hour), Min-Max normalization, inverse scaling
- **Tools & Libraries:** Python, TensorFlow, Keras, XGBoost, statsmodels, matplotlib, seaborn
- **Evaluation Metrics:** MAE, MSE, RMSE, R²

---

## 🏆 Key Achievement

✅ Improved prediction accuracy compared to baseline models:

- ↓ **31.13% MSE**
- ↓ **19.03% MAE**
- ↑ **2% R²**

Demonstrated robust AQI prediction for multiple pollutants (**PM2.5, PM10, NO2, SO2, CO, O3**).
